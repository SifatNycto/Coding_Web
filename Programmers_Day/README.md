## 🌌 About

**Happy Programmer Day** is a single-page interactive website built specifically to celebrate **Programmer Day — September 13**.

The project combines a dark futuristic aesthetic with coding-inspired visuals, animations, interactive elements, and developer culture.

It is intentionally built as a **single self-contained HTML file** using only:

- HTML
- CSS
- JavaScript
- Canvas API

No frameworks, libraries, packages, or external dependencies are required.

> **We don't just write code.  
> We write possibilities.**

## ✨ Features

### 🟢 Matrix Rain

A continuously animated Matrix-style background is rendered using the HTML Canvas API and JavaScript.

The effect automatically adapts to the browser window size.

### ⚡ Glitch & Neon Typography

The main `PROGRAMMER` title features:

- Neon glow
- Glitch layers
- Animated text effects
- Cyberpunk-inspired typography

### ⌨️ Interactive Code Window

The website contains a simulated code editor showing a programmer-themed JavaScript class:

```javascript
class Programmer {

    constructor() {
        this.dreams = Infinity;
        this.coffee = Infinity;
        this.bugs = "temporary";
    }

    build() {
        while (this.dreams) {
            this.learn();
            this.code();
            this.debug();
            this.improve();
        }
    }

    impact() {
        return "Make something that matters.";
    }
}
